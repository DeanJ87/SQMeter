# Implementation Plan: UI design system and copy

**Branch**: `spec/026-ui-design-system` | **Spec**: [spec.md](spec.md) | **Audit**: [audit.md](audit.md)

## Summary

Write the design system down (DS-01..DS-10, DS-20..DS-27) in the coding standard, enforce what can be
checked, and bring the UI back onto it: a Status card replaces the glance strip, the language switch
reports inside the Language card, addresses become rows, explanations move behind "?", and the
English copy is rewritten (translations regenerated). The owner approved the mockups (SC-005) with two
corrections, both applied here:

1. Status card problems are one row each: the name on the left, a pill on the right, the whole row
   links to where it's fixed. No repeated "Open settings", no "Name (MODEL): Error" strings.
2. The language result in the Language card is a pill (Downloading / Installed / Failed …) with a
   progress meter, never coloured monospace text.

## Technical context

- Web UI only, apart from sensor names the device sends as text (none needed: the dashboard names
  sensors itself). Firmware unchanged.
- Preact + existing components in `web/src/components/ui.tsx` (Card, MetricTile, ReadingRow, Pill,
  Note, InfoTip, ProgressMeter). No new component library; two small compositions: `StatusCard`
  (dashboard) and the in-card language progress.
- i18n: English source `web/src/i18n/en.json` + `en.context.json`; 13 locales regenerated by hand
  from the new English using the glossaries (no API key in this environment), then
  `translate.py --record`.
- Budgets: UI growth ≤ 10 KB gzipped (SIZE-01); the strip, banner and notice code is removed, so
  growth should be near zero.

## Constitution check

- I (spec first): spec + reviewed mockups exist; this plan cites them.
- IV (budgets): SIZE-01 checked by `tools/ui/size_check.py`.
- VIII (quality): new checks join the quality gate (copy DS-xx, labels, layout).
- Accessibility (022): Status rows are links/buttons with visible text; pills carry text; the
  verdict announcement moves with the card.

## Design decisions

| # | Decision | Why |
|---|---|---|
| D1 | `StatusCard` is a normal Masonry card, id `status`, first in `DEFAULT_ORDER`, movable. | DS-01, FR-001 |
| D2 | Tiles: Safety, Alerts, Data always; one Imaging app tile per device when spec 025's relevance rule says so. Each tile: label, pill, one sub line. | FR-002, DS-03, DS-21 |
| D3 | Alerts tile carries its own action (Resume) when paused; Phone alarm row carries Acknowledge. Other rows link. | one action per problem (FR-002) |
| D4 | A problem row = `<a>` (or `<button>` for actions) with the short name and a pill; the "?" sits after the link, outside it (no nested interactive controls). | correction 1, A11Y |
| D5 | Sensor rows: name only ("IR sky sensor"), pill = state ("Error", "Not responding", "Stale"), "?" = what it costs + last reading. | correction 1, DS-24 |
| D6 | Card pill: "All good" (green) or "{n} to check" (red if any problem, else amber). | FR-003 |
| D7 | Demo marker leaves the dashboard; the Demo panel button already says "Demo" and now also "Clock moved" when shifted. | spec edge case |
| D8 | Language: header banner and page-wide notice removed. The Language card shows a status row (language name + pill), a `ProgressMeter` while downloading, then a one-line Note with Retry and "?". The Status card lists a missing/failed language as one row linking to Settings → Device → Language. | FR-004, correction 2 |
| D9 | Device & Network: Wi-Fi and Uptime tiles; IPv4, IPv6 (one row per address, scope label + "?" for non-global), Local name, MQTT and Firmware as rows; long values truncate with the full value in `title`. | FR-005, DS-05 |
| D10 | Sun & Moon: the time-zone sentence becomes the card hint. | FR-006, DS-26 |
| D11 | Copy check (`tools/quality/copy_check.py`): types come from the key's context note (`label`, `pill`, `note`, `hint`); limits 24/16/90/160 chars for English; banned phrases; `·` joins. Run in the quality gate as DS-COPY. | FR-012 |
| D12 | Label check (`tools/quality/label_check.py`): sensor and feature names from `tools/i18n/glossary/en.json` must be the ones used in `en.json` sensor keys, alert templates and the docs glossary. | FR-013 |
| D13 | Layout check: Playwright asserts nothing sits between the header and the card grid at 1280 and 390 px. | FR-014 |
| D14 | Illuminance uses significant figures (`formatIlluminance`, 3 s.f., grouped) everywhere it's shown. | A12 |
